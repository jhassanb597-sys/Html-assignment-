HTML — HyperText Markup Language

The skeleton of every webpage. HTML gives structure and meaning to content.

Headings

HTML has six heading levels from <h1> (largest) to <h6> (smallest).

Heading h1

Heading h2

Heading h6 — the smallest heading

Text Formatting

Bold uses <b> tag.

Italic uses <i> tag.

Strong uses <strong> — tells the browser this text is important.

Emphasized uses <em> — italic with semantic importance.

Lists

Ordered list (numbered steps):

  1. Morning time activities
  2. Evening time activities
  3. Night activities

Unordered list (bullet points):

  • We use <li> tags here
  • For unordered, <ul> tag is used
  • Each point uses an <li> tag

Definition list:

<dt> — Definition Term
The term being defined
<dd> — Definition Description
The meaning or description of that term

#css

CSS — Cascading Style Sheets

CSS makes the page beautiful. It controls colors, fonts, spacing, layout and animations.

Selectors

CSS selects elements using tags, classes (.classname), and IDs (#idname).

  • p { color: white; } — selects all <p> tags
  • .pclass { background: pink; } — selects by class
  • #boldp { font-weight: bold; } — selects by ID

Font Weight & Size

Bold text — font-weight: bold

Light text — font-weight: lighter

font-weight: 300 (thin)

font-weight: 900 (black / heaviest)

font-size: 25px — larger than default 16px

Display Property

display controls how elements are laid out on the page.

This div uses display: inline-block

The <div> is normally block-level. With display: inline-block it sits beside other inline elements like this button.

Colors & Backgrounds

Aqua
Yellow
Pink

Colors can be set by name, hex #ff6600, RGB rgb(200,50,90), or RGBA with opacity rgba(0,0,0,0.5).

Anchor / Link Styling

CSS removes the default underline from links using text-decoration: none.

Facebook — styled link (no underline)
